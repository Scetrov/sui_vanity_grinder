# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch. Older
versions and forks may not receive security updates.

## Reporting a vulnerability

Please use this repository's [private vulnerability reporting](https://github.com/Scetrov/sui_vanity_grinder/security/advisories/new) flow. Do not disclose suspected vulnerabilities in a public issue.

Please include a clear description, reproduction steps, and the potential impact. We aim to acknowledge vulnerability reports within 7 days and provide a status update within 30 days. Disclosure timing will be coordinated with the reporter after a fix is available.
